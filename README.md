##  Course Description

This course introduces the fundamentals of **C# programming** and Windows application development.

Students learn how to write C# programs, work with data, make decisions, use loops, create methods, work with arrays and lists, handle files, connect applications to databases, and develop desktop applications using **Windows Forms**.

The course also introduces **event-driven programming** and practical problem-solving using C#.



##  Course Objectives

By the end of this course, students should be able to:

* Understand the fundamentals of C# programming.
* Apply programming logic and problem-solving techniques.
* Understand event-driven programming.
* Develop graphical user interface applications.
* Work with methods, arrays, lists, and files.
* Connect C# applications with databases.
* Develop desktop applications.
